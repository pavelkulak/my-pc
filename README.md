# CFV235 Studio

Статическая страница с настоящей GLB-моделью существующей сборки. SSD не добавлен.

## Публикация через Vercel

Импортируйте репозиторий `pavelkulak/my-pc` в Vercel. В `vercel.json` уже заданы статическая публикация, пропуск установки зависимостей и сборки, выходная папка `dist`. Root Directory — корень репозитория. Если настройки вводятся вручную: Framework Preset `Other`, Build Command пустой, Output Directory `dist`.

Вся модель, четыре текстуры, Three.js и Draco-декодер включены в репозиторий. Для публикации Blender, npm install и внешний CDN не требуются. После подключения Git новые коммиты в production-ветку будут автоматически обновлять сайт.

## Запуск локально

Из этой папки: `node serve.mjs`, затем http://localhost:4318. Нужен HTTP-сервер: открытие index.html через file:// не подходит для модульного JavaScript и загрузки модели. Зависимости устанавливать не нужно, Three.js 0.185.1 и Draco-декодер включены в dist/vendor. Через `PORT` можно выбрать другой порт.

## Управление

- Питание: плавный запуск/остановка 11 роторов, включение/выключение ARGB. Начальное состояние выключено. Ту же кнопку можно нажать на самом корпусе.
- Общие цвет и яркость: штатный задний вентилятор, Unity240, Unity360-FB, ленты Aurora, T-Force Delta RGB. Башня Thermalright Royal Knight 120 и PowerColor Reaper не окрашиваются.
- Статичный свет, синхронное дыхание или синхронный спектр. Никаких независимых зон. Цвет можно выбрать до включения.
- Световые детали без питания молочно-белые, интенсивность свечения нулевая. Чёрные непрозрачные детали остаются чёрными.
- Боковое и переднее стекло снимаются кликом; вернуть их можно из панели. Крышка снимается отдельно. Вращение модели не считается кликом.
- Вращение мышью/пальцем, приближение, четыре ракурса и сброс камеры. При системном запросе reduced motion вращение роторов отключено.

## Стекло

Three.js MeshPhysicalMaterial: transmission 0.98, IOR 1.47, толщина 4 мм, roughness 0.035, лёгкая нейтральная тонировка, отражения среды. Это физическое пропускание света, не просто alpha. Стекло не отбрасывает непрозрачную тень на внутренности. Оба стекла по умолчанию установлены на странице. Скрытое состояние в исходном Blender сохранено.

Основы: https://threejs.org/docs/pages/MeshPhysicalMaterial.html и https://threejs.org/examples/webgl_loader_gltf_transmission.html . Значения материалов подобраны для демонстрации; оттенок и оптика реального стекла по фото точно не измеряются.

## Ассеты и проверка

Экспорт: ../pc-model/export_web.py. Исходник: pc_assembly_v007.blend. Статика объединена по компонентам, роторы сохранены с осями и центрами. 11 вращающихся групп, 6 корпусных RGB-роторов, 2 стекла, 1 крышка. Изображения компонентов упакованы в GLB; геометрия сжата Draco. Стекло настроено в коде страницы. Неиспользуемый исходный куб, сцены освещения Blender и снятые заглушки не экспортируются.

`node --check dist/app.js`, `node --check dist/state.js`, `node validate.mjs` проверяют синтаксис, ресурсы, GLB-контракт, импортируемые модули и состояние питания/света. По прямой просьбе пользователя браузерная и визуальная проверка не выполнялась.

Поддержка ARGB корпуса подтверждена официальной спецификацией: https://cougargaming.com/products/cases/cfv235/ . Для геометрии и фото компонентов см. ../pc-model/*SOURCES.md. Полной заводской CAD-точности модель не заявляет. Провода питания и Wi-Fi-адаптер на текущем этапе отсутствуют.
